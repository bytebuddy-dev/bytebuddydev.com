Guide

What is a SKILL.md?

An Agent Skill is a folder that teaches an AI agent how to do one job well. Its only required file is SKILL.md: a few lines of YAML frontmatter, then Markdown instructions. Agents such as Claude load only each skill's name and description at startup (about 100 tokens each), then read the full file when a task matches. That is why one agent can carry dozens of skills without filling its context window.

commit-messages/
├── SKILL.md        # required: frontmatter + instructions
├── scripts/        # optional: code the agent can run
├── references/     # optional: extra docs, loaded only when needed
└── assets/         # optional: templates, images, data

Where to save it

  • Claude Code, all projects: ~/.claude/skills/<skill-name>/SKILL.md
  • Claude Code, one project (shared with your team): .claude/skills/<skill-name>/SKILL.md
  • Other agents: check where your agent loads skills from. The folder name must still match name.

In Claude Code you can also run a skill directly by typing /skill-name. Set disable-model-invocation: true if it should only ever run when you type the command, for example a deploy skill.

Write a description that actually triggers

The description is the only thing the agent sees before deciding to load your skill. Compare:

❌ Too vague✅ Specific
Helps with PDFs.Extracts text and tables from PDF files, fills PDF forms, and merges multiple PDFs. Use when working with PDF documents or when the user mentions PDFs, forms, or document extraction.
I can write commits for you.Writes Conventional Commit messages from staged git changes. Use when the user asks to commit or describe their changes.

Good descriptions name the task, the file types or tools, and the words a user would actually say. The PDF example above is the one used in the official spec.

FAQ

What is a SKILL.md file?

A SKILL.md is the main file of an Agent Skill: a folder of instructions (and optional scripts and resources) that an AI agent such as Claude loads only when a task needs it. The file starts with YAML frontmatter (name and description) followed by Markdown instructions.

Where do I put a SKILL.md for Claude Code?

Personal skills go in ~/.claude/skills/<skill-name>/SKILL.md and work in every project. Project skills go in .claude/skills/<skill-name>/SKILL.md inside the repo, so your team gets them too.

How long can the description be?

Up to 1,024 characters in the Agent Skills spec. It must not be empty, and it should say both what the skill does and when to use it, because that is what the agent reads to decide whether to load the skill.

Why does my skill never trigger?

Almost always the description. Make it specific: name the task, the file types or tools involved, and the phrases a user would say ("Use when the user asks to…"). A vague description like "Helps with PDFs" gives the agent nothing to match.

Can I use the same SKILL.md with other AI agents?

Yes, if you stick to the standard fields (name, description, license, compatibility, metadata, allowed-tools). Claude Code adds extra fields such as argument-hint and disable-model-invocation that other agents may ignore or reject.

Does this tool upload my skill anywhere?

No. The generator and validator run entirely in your browser. Nothing you type is sent to a server.
