About Byte Buddy

Byte Buddy is a tech channel for developers and curious people. We make short videos on YouTube, Instagram and TikTok about three things:

  • AI coding tools: Claude Code, MCP servers, agents and prompting, shown on real projects.
  • How tech works: the engineering behind games, apps and everyday software.
  • Free developer resources: GitHub repos, tools, APIs and websites worth bookmarking.

Meet the hosts

Bugsy is a junior developer who ships fast and fixes things… eventually. He's the 3D bug on this site (go on, poke him). His mentor Patch is a walking band-aid with tired eyes and a coffee mug, who has seen every bug before.

How we check things

  • Every repo in a list is checked on GitHub before it's used: it exists, it isn't archived and it's still maintained.
  • Code shown in a video is run before it goes on screen.
  • When an AI tool gets something wrong in a build, we show it. The GTA portfolio page lists all 8 mistakes.
