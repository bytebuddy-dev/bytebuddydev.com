🧠 Claude Skills

10 Claude Skills repos that feel illegal to know

Skills are folders of instructions (a SKILL.md plus optional scripts) that Claude loads only when a task needs them. These ten free repos give you hundreds of them.

Star counts checked on GitHub on 25 November 2026. Descriptions and install commands come from each repo's README.

How to install: in Claude Code, /plugin marketplace add owner/repo registers a repo, then /plugin install adds a plugin from it. Repos that follow the open Agent Skills format also work with npx skills add owner/repo.

1obra/superpowers

★ 326K stars

Claude stops jumping straight into code. It asks what you want, writes a plan, then builds it test-first.

Why it's worth it: It can work on its own for hours.

/plugin install superpowers@claude-plugins-official

2anthropics/skills

★ 200K stars

Anthropic's own skills, including the ones behind Claude's Word, PDF, PowerPoint and Excel files.

Why it's worth it: Read how Anthropic writes skills.

/plugin marketplace add anthropics/skills

3nextlevelbuilder/ui-ux-pro-max-skill

★ 154K stars

Generates a full design system for your app: styles, colour palettes, fonts and UX rules.

Why it's worth it: Your AI-built app stops looking AI-built.

/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill

4K-Dense-AI/scientific-agent-skills

★ 58K stars

177 science skills and 100+ databases: biology, chemistry, medicine, physics and more.

Why it's worth it: Turns your coding agent into a lab assistant.

Install: see the README for your agent.

5vercel-labs/agent-skills

★ 35K stars

Vercel's official skills: React & Next.js performance rules and an audit of your Vercel costs.

Why it's worth it: The framework team's own playbook.

npx skills add vercel-labs/agent-skills

6alirezarezvani/claude-skills

★ 30K stars

434 skills that go way past code: marketing, product, compliance, finance, even C-suite advice.

Why it's worth it: A whole company in one repo.

/plugin marketplace add alirezarezvani/claude-skills

7OthmanAdi/planning-with-files

★ 28K stars

Keeps Claude's plan in Markdown files on disk, so it picks up where it left off after /clear or a crash.

Why it's worth it: Manus-style memory for long tasks.

npx skills add OthmanAdi/planning-with-files -g

8Jeffallan/claude-skills

★ 12.5K stars

71 skills for full-stack devs: frameworks, APIs, testing, DevOps, security and data/ML.

Why it's worth it: A specialist for every layer of your stack.

/plugin marketplace add jeffallan/claude-skills

9remotion-dev/skills

★ 8K stars

Make videos with code. Type "/remotion-create Make a promo video for a record store".

Why it's worth it: Our own videos are built with Remotion.

npx skills add remotion-dev/skills

10lackeyjb/playwright-skill

★ 3.3K stars

Claude writes and runs browser tests, then shows you screenshots and console output.

Why it's worth it: "Test if my site loads" just works.

/plugin marketplace add lackeyjb/playwright-skill
